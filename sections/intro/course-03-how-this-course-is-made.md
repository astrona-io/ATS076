# How This Course Is Made

Authors map sections to the official OpenTelemetry Certified Associate (OTCA) objectives and check mechanisms against primary documentation. They review examples for responsible components, prerequisites and meaningful failure cases.

Structural checks verify reading order, section introductions, closing summaries, draft metadata and YAML question contracts. Labs and playgrounds are checked statically with `astrona validate`, shell syntax checks and YAML parsing. Nobody has run them yet, and each lab README says UNTESTED.

The [contributors](https://github.com/astrona-io/ATS076/graphs/contributors) maintain the material. To [report a mistake](https://github.com/astrona-io/ATS076/issues), identify the page and disputed statement. The [license](https://github.com/astrona-io/ATS076/blob/main/LICENSE) governs reuse.

Objectives belong to their respective owners. Teaching and knowledge checks are original practice material. Application names are illustrative and have no special technical meaning.
