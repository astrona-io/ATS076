# Welcome To The Course

This course develops the official Maintaining and Debugging Observability Pipelines objectives for OpenTelemetry Certified Associate (OTCA). The certification uses a multiple-choice examination. The course is independently authored and does not claim to simulate the examination.

Each section starts with its own introduction and learning outcomes. Each module has goals, two teaching parts, a playground, a graded lab and a closing summary. Each section ends with a capstone lab and a quiz, and the course ends with a final domain quiz.

The labs run on a local kind cluster with the OpenTelemetry Collector. The example workloads are `shuttle`, `probe`, `gateway` and `edge` in the `starfleet` namespace, and the Collector in the `observability` namespace.

Read each part, run the commands in the playground and then solve the lab on the next page. The labs were built without being run, so a lab can contain a mistake. Report it with the page and the step.
